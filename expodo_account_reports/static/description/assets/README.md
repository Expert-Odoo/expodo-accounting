# Captures d'écran de la page App Store

Les fichiers attendus ici, référencés par `../index.html` :

| Fichier             | Contenu                                             |
|---------------------|-----------------------------------------------------|
| `tax_report.jpg`    | Déclaration de TVA (CA3) affichée                   |
| `balance.jpg`       | Balance générale dépliée par compte                 |
| `grand_livre.jpg`   | Grand livre déplié sur un compte, pièce par pièce   |
| `aged.jpg`          | Balance âgée clients, six tranches                  |
| `bilan.jpg`         | Bilan au format PCG                                 |
| `compte_resultat.jpg` | Compte de résultat au format PCG                  |

À ajouter également, hors de ce dossier :

* `../banner.png` — vignette de l'App Store, référencée par le manifeste
* `../icon.png` — icône du module, 140×140 px

Les captures doivent montrer des **montants vraisemblables**. Une capture avec
des montants à zéro ou des libellés de test dessert le module plus qu'elle ne
l'aide : elle suggère qu'il n'a jamais servi.
